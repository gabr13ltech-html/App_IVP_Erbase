Esse projeto é uma iniciativa de alunos do IFS-Campus Lagarto para facilitar o estudo do método de valoração e ferramenta técnica IVP (Índice de Valor Paisagístico).
O app vem com um sistema simples de identificação de árvores, onde você põe o arquivo e a espécie é detectada com a biblioteca de dados 
externa Pl@ntNet e entrega uma resposta com a porcentagem de afinidade com a árvore desejada. 
O app conta também com explicações do que é a ferramenta IVP, como calcular, critérios e etc.
